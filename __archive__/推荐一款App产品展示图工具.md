## 三、JS / CSS 库（适合前端集成）

| 库名称                    | 安装方式                      | 特点                                                              | 适用场景                    |
| ------------------------- | ----------------------------- | ----------------------------------------------------------------- | --------------------------- |
| **react-device-frameset** | `npm i react-device-frameset` | React 组件；高质量 CSS/SVG 设备外壳；支持 MacBook Pro/iPhone X 等 | React 项目官网动态展示      |
| **html5-device-mockups**  | `npm i html5-device-mockups`  | 纯 CSS/HTML；86 种设备图片；多配色多方向                          | 网页嵌入展示 / CI 自动化    |
| **Devices.css**           | CSS 引入                      | 纯 CSS 实现；轻量无依赖；扁平化风格                               | 简单静态页面                |
| **mj-mockup-generator**   | `npm i mj-mockup-generator`   | API 驱动生成 mockup；支持多设备型号                               | 自动化流水线 / 需 API Token |
| **moqq**                  | `npm i -g moqq`               | Node.js 工具；使用 Jimp 合成图像；支持 PC + iPhone X              | CLI 批量生成                |
