# 入门指南 最后更新时间: 2023年03月31日

地图组件是一类高度模块化的LBS服务组件，开发者通过调用相应标签便可轻松实现诸如在地图上标注点、查找附近poi、公交/驾车线路规划等功能。该类组件仅针对手机浏览器类的应用，与API相比，标签方式调用更为简单，模块化程度更高，可以极大地降低开发成本。 

## 获取高德Key

### 第一步 注册高德账户 

如您已经[注册](https://lbs.amap.com/dev/id/newuser)过，请直接[登录>>>](https://lbs.amap.com/api/lightmap/gettingstarted)

### 第二步 申请成为高德开发者 

您可选择注册成为个人认证开发者或企业认证开发者。[现在去申请>>>](https://lbs.amap.com/dev/id/newuser)

### 第三步 进入控制台申请应用及Key 

进入[控制台>>>](https://lbs.amap.com/dev/index)。先创建一个应用，再创建该应用的KEY。 

![](https://a.amap.com/lbs/static/img/create.png)

![](https://a.amap.com/lbs/static/img/application.png)

注意：地图组件使用的Key对应的产品是JavaScript API  

![](https://a.amap.com/lbs/static/img/component.png)
