如果你用过 Claude Code、Cursor、Windsurf 这些 AI 编程工具，你一定对 @ 符号不陌生——输入 @ 就能快速引用文件，非常直观高效。

用习惯之后，我回到 Obsidian 写笔记时就很难受：想引用一个文件路径，要么手动敲，要么切出去复制粘贴，特别打断思路。

我就想，Obsidian 作为一个以文件为核心的笔记工具，怎么能没有这个功能呢？

找了一圈，社区里确实没有好用的方案。那就自己动手吧——于是就有了 Mention Path 这个插件。

现在，你在 Obsidian 里也能像在 Claude Code 里一样，打个 @ 就能快速插入文件路径了。

## 核心特性
### 1. Trigger-based Autocomplete

它的核心功能非常简单：在笔记里输入 @ 符号，就能快速插入文件路径。

你看，我只要打一个 @，当前目录下的所有文件和文件夹就出来了。而且它很智能，只有在空格后面或者行首输入才会触发，不会干扰你正常打字。
### 2. Parent Directory Navigation

如果我想引用上级目录的文件怎么办？

很简单，输入 ../ 就能跳到父目录。想往上跳两级？那就 ../../，和命令行的习惯完全一致。
### 3. Vault Root Quick Access

有时候文件在 vault 根目录，一层层往上跳太麻烦了。

这时候直接输入 ~/，一步到位跳到 vault 根目录，然后从根目录往下找就行了。
### 4. Folder Drill-down

这个插件有个很贴心的设计：当你选中一个文件夹时，它不会关闭候选框，而是直接进入这个文件夹继续浏览。

这样你可以一路点下去，直到找到目标文件，整个过程非常流畅。
### 5. Recursive Search

文件太多找不到？没关系，直接输入关键词。

你看，我输入 readme，它会自动搜索当前目录下所有子文件夹，把匹配的结果都列出来，还会显示相对路径，一目了然。
### 6. Smart Sorting

搜索结果的排序也是精心设计的。

你看，最上面是 ~/ 和 ../ 这些快捷导航，然后是文件夹，最后才是文件。同类型的按字母排序，层级浅的排在前面。这样最常用的选项总是在最上面。
### 7. Relative Path Insertion

选中文件后，插入的是相对路径，不是绝对路径。

这有什么好处？你的笔记移动位置、换电脑同步，这些路径引用都不会失效。
### 8. Customizable Trigger

最后，如果你不喜欢用 @ 作为触发符，可以在设置里改成任意字符。

比如改成 # 或者 /，完全看你的习惯。
