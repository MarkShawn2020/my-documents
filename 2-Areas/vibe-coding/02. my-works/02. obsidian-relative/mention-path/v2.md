# 在 Obsidian 里输入 @，像 Claude Code 一样引用文件

用过 Claude Code、Cursor、Windsurf 的朋友都知道，**@ 符号** 是这些 AI 编程工具的灵魂交互——输入 @，文件列表弹出，选中即引用，行云流水。

但当我回到 Obsidian 写笔记时，这种丝滑感戛然而止。

想引用一个文件路径？要么手敲，要么切出去复制粘贴。每一次操作都在打断思路，每一次中断都在消耗心流。

我就想：Obsidian 作为一个 **以文件为核心** 的笔记工具，怎么能没有这个功能？

找了一圈，社区里确实没有好用的方案。

那就自己动手——于是就有了 **Mention Path**。

![](http://cdn.cs-magic.cn/picgo/demo.gif)

## 为什么需要路径引用

在笔记中引用文件路径是个高频需求：

- 写技术文档时，需要引用配置文件、脚本路径
- 整理项目笔记时，需要链接到具体的代码文件
- 做知识管理时，需要记录资源的存放位置

传统方式要么依赖记忆手敲，要么切换窗口复制——这些「微操作」看似不起眼，累积起来却是巨大的效率黑洞。

```ad-tip
在 Claude Code 等工具中，@ 作为「上下文引用符」已成为事实标准。它的优势在于：单字符触发、语义直观、不干扰正常输入。Mention Path 将这一范式带入 Obsidian。
```

## 核心能力一览

### 智能触发，不打扰正常输入

输入 @ 符号，当前目录下的文件和文件夹立即呈现。

关键在于 **智能判断**：只在空格后或行首触发，不会干扰你正常打字中的 @ 符号（比如邮箱地址）。

### 目录导航，和命令行一样直觉

- `../` — 跳转上级目录
- `../../` — 往上两级
- `~/` — 一步到位回到 Vault 根目录

这套语法和终端完全一致，零学习成本。

<!-- 评注建议：可以强调这是"肌肉记忆复用"，降低认知负担 -->

### 文件夹穿透，一路点到底

选中文件夹时，候选框不会关闭，而是 **直接进入该文件夹** 继续浏览。

一路点下去，直到找到目标文件，整个过程无需键盘切换，非常流畅。

### 递归搜索，关键词定位

文件太多？直接输入关键词。

插件会自动搜索当前目录下 **所有子文件夹**，把匹配结果连同相对路径一并列出。

### 智能排序，常用优先

搜索结果的排序逻辑：

1. 快捷导航（`~/`、`../`）置顶
2. 文件夹优先于文件
3. 同类型按字母排序，层级浅的靠前

最常用的选项，永远在最上面。

### 相对路径，跨设备不失效

插入的是 **相对路径**，而非绝对路径。

好处显而易见：笔记移动位置、换电脑同步，路径引用依然有效。

### 触发符可自定义

不喜欢 @？在设置里改成 `#`、`/` 或任意字符，完全随你。
