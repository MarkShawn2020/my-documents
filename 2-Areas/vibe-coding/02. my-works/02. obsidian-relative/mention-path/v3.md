# Vibe Coding 用久了，我给 Obsidian 也装上了 @ 引用

最近 **Vibe Coding** 这个词很火。

简单说就是：你只管描述意图，AI 帮你写代码，整个过程行云流水，沉浸感拉满。

Claude Code、Cursor、Windsurf 这些工具之所以让人上头，不只是因为 AI 能力强，更因为交互设计足够丝滑——比如那个 **@ 符号**，输入即引用，零摩擦。

```ad-tip
Andrej Karpathy 提出的概念：完全沉浸在 AI 辅助编程的心流中，忘记语法细节，专注于创意和意图表达。核心是"氛围感"——工具不打断你，你不迁就工具。
```

但问题来了：**Vibe Coding 用久了，回到 Obsidian 写笔记时特别难受。**

想引用一个文件路径？要么手敲，要么切出去复制粘贴。每一次操作都在打断思路，每一次中断都在消耗心流。

我就想：Obsidian 作为一个以文件为核心的笔记工具，凭什么不能也 Vibe 起来？

找了一圈，社区里确实没有好用的方案。

那就自己动手——于是就有了 **Mention Path**。

## 从 Vibe Coding 到 Vibe Writing

在笔记中引用文件路径是个高频需求：

- 写技术文档时，引用配置文件、脚本路径
- 整理项目笔记时，链接到具体的代码文件
- 做知识管理时，记录资源的存放位置

传统方式依赖记忆手敲或切换窗口复制——这些「微操作」看似不起眼，累积起来却是心流的最大杀手。

**Mention Path 的设计理念**：把 Claude Code 里那套 @ 引用的交互范式，原封不动搬进 Obsidian。

## 核心能力

### 智能触发，不干扰正常输入

输入 @，当前目录下的文件和文件夹立即呈现。

只在空格后或行首触发，不会误伤邮箱地址里的 @。

### 目录导航，终端直觉

- `../` — 上级目录
- `../../` — 往上两级
- `~/` — 一步回到 Vault 根目录

和命令行语法完全一致，**肌肉记忆直接复用**。

### 文件夹穿透

选中文件夹不会关闭候选框，而是直接进入继续浏览。一路点到底，找到目标文件。

### 递归搜索

输入关键词，自动搜索所有子文件夹，匹配结果连同相对路径一并列出。

### 相对路径插入

插入的是相对路径，笔记移动、跨设备同步，引用永不失效。

### 触发符可自定义

不喜欢 @？改成 `#`、`/` 或任意字符。
