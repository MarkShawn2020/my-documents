像我们这种重度冲浪、经常记笔记以及写文章的朋友来说，很需要能够以各种方式（右键、快捷键）各种格式（标题+链接、markdown等）方式快捷复制网站信息。

在很多年以内，我都是考 一个好像叫 Sample Editor CommandTabList 的插件实现的，它很小巧，但在好像一年前该插件似乎提示有滥用还是不兼容啥的，anyway，似乎被下架了，现在再搜已经找不到了（因为我还记得它那个黑里透白的logo）：

![](http://cdn.cs-magic.cn/picgo/20251128151030435.png)

而在过去的几个月，我开发了Lovpen Sider，它原计划是做成类似 Monica 或者 Sider 那样比较全能的浏览器侧边栏AI助理，并提供一些有用的帮助我创作的功能，例如提取网页内容、快捷复制标题等。

![测试过程中发现Monica的侧边栏竟然有登录bug🤔](http://cdn.cs-magic.cn/picgo/20251128180227225.png)



后来我发现，我对在浏览器侧边栏提供一个强大的AI助理这个事情，目前没有特别大的执念，尽管我的好朋友纷纷下场做了很多相关的探索，例如做了一款AI浏览器，尽管我个人觉得，在大部分情况下可能一个侧边栏助理似乎就能解决大部分需求了。

![](http://cdn.cs-magic.cn/picgo/20251128180556477.png)

尽管我后续在开发Lovpen Sider的过程中，又否定了这个看法，因为Chrome插件似乎有很多限制，例如最多只能配四个快捷键，以及不能抢夺Chrome自己的快捷键（例如 cmd + shift + C 是打开Element的功能，你都不知道为啥他们要配置一个这样的快捷键），这对于对快捷键有执念的我来说，是近乎不能接受的。

![](http://cdn.cs-magic.cn/picgo/20251128180614924.png)
