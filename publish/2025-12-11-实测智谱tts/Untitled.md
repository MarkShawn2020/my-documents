# wow

macOS 自带的“语音备忘录”默认录制格式是 `.m4a`（Apple MPEG-4 音频），不直接提供“另存为 MP3”的菜单选项。

要将其导出为 MP3 或 WAV，你有以下几种方法，按**推荐程度**排序：

### 方法一：使用“快捷指令” (最快、无需安装新软件)
这是 macOS 系统自带的最强功能，设置一次后，以后只需右键点击即可转换。

1.  打开 Mac 上的 **“快捷指令” (Shortcuts)** 应用。
2.  点击右上角的 **“+”** 号新建一个快捷指令。
3.  在右侧搜索栏输入 **“编码媒体” (Encode Media)**，将其拖入左侧流程图。
    *   点击“编码”那一栏的展开箭头，将格式改为 **Audio Only** (仅音频)。
    *   格式选择 **MP3** 或 **WAV**（AIFF）。
4.  在右侧搜索栏输入 **“存储文件” (Save File)**，将其拖到“编码媒体”的下方。
5.  在右侧边栏的 **“快捷指令详细信息” (i 图标)** 中，勾选 **“在访达中用作快速操作” (Use as Quick Action)**。
6.  给这个快捷指令起个名字（例如“转为 MP3”）。
7.  **使用方法**：
    *   将语音备忘录拖拽到桌面（变成 .m4a 文件）。
    *   右键点击该文件 -> **快速操作 (Quick Actions)** -> 选择你刚才创建的 **“转为 MP3”**。
    *   转换后的文件会自动保存。

---

### 方法二：使用“音乐” (Music) 应用 (系统原生方法)
如果你不想折腾快捷指令，可以用系统自带的“音乐”应用来进行格式转换。

1.  **准备文件**：从“语音备忘录”中，把录音直接拖拽到桌面（此时是 .m4a 格式）。
2.  **修改导入设置**：
    *   打开 **“音乐” (Music)** 应用。
    *   按 `Cmd + ,` 打开偏好设置（或者点击菜单栏 音乐 -> 设置）。
    *   点击 **“文件” (Files)** 选项卡 -> 点击 **“导入设置” (Import Settings)**。
    *   在“导入时使用”下拉菜单中，选择 **“MP3 编码器”** 或 **“WAV 编码器”**，然后点击确定。
3.  **转换文件**：
    *   按住 `Option` (Alt) 键，同时点击菜单栏的 **文件 (File)** -> **转换 (Convert)** -> **“转换为 MP3/WAV 版本”**。
    *   此时会弹出一个窗口，选择你桌面上的那个录音文件。
    *   转换完成后，新文件会出现在“音乐”库中。
    *   右键点击库里的新文件 -> **“在访达中显示”** 即可找到 MP3/WAV 文件。

---

### 方法三：使用在线转换网站 (最简单，适合偶尔使用)
如果你只需要转换一两个文件，且录音内容不涉及隐私，这是最简单的方法。

1.  从“语音备忘录”中，把录音拖拽到桌面。
2.  打开浏览器，搜索 “m4a to mp3” (推荐网站如：CloudConvert, Convertio, Zamzar 等)。
3.  上传文件，选择输出格式为 MP3 或 WAV。
4.  等待转换完成并下载。
    *   *注意：如果录音涉及重要隐私或商业机密，请不要使用此方法。*

---

### 方法四：使用 GarageBand (适合需要简单剪辑的情况)
Mac 自带的 GarageBand 也可以导出。

1.  打开 GarageBand，新建一个空项目。
2.  将语音备忘录拖入轨道。
3.  点击菜单栏 **“共享” (Share)** -> **“将乐曲导出到磁盘” (Export Song to Disk)**。
4.  在弹出的窗口中，选择 **MP3** 或 **WAVE**，选择质量，然后点击导出。

### 总结
*   **最高效**：设置一个**“快捷指令”**（方法一），一劳永逸。
*   **最原生**：使用 **“音乐”App**（方法二）。
*   **最省事**（非隐私文件）：**在线转换**（方法三）。
