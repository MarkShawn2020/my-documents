

OpenAgents 社区在搞一个 Multi-Agent Hackathon，总奖金 15000 元，12 月整月都可以参赛。

说实话，我个人目前的工作流还是深度依赖单循环 Agent——Claude Code 就是个典型例子，一个 Agent、一个上下文、一路执行到底。简单、可控、符合直觉。

但我越来越觉得，**单 Agent 的天花板，可能就是 2025 年 Multi-Agent 的起跑线**。

---

## 为什么这么说？

单 Agent 再强，本质上还是"一个大脑在干活"。它的极限取决于：上下文窗口有多大、工具调用有多稳、推理链条能撑多长。

而 Multi-Agent 解决的是另一个层面的问题：**当任务复杂到一个 Agent 装不下时，怎么让多个 Agent 协作、分工、甚至互相校验？**

这不是"更多Agent = 更强"的简单加法。真正的难点在于：

- **发现机制**：Agent A 怎么知道 Agent B 存在、能干什么？
- **协作协议**：它们用什么"语言"交流？谁来协调？
- **信任与验证**：一个 Agent 的输出，另一个怎么判断可不可信？

这些问题，目前整个行业都还在探索。

---

## OpenAgents 在做什么？

OpenAgents 想做的事情，用他们自己的话说，是"开放协作的 AI Agent 网络"——让 Agent（或人类）可以与其他数百万 Agent 共同工作、共享资源、攻克长期项目。

有点像 Agent 世界的"互联网协议层"。

从技术方向上看，这个赛道值得关注——如果 2024 年是单 Agent 应用爆发的一年，2025 年很可能是 Multi-Agent 基础设施逐渐成型的一年。

## 关于这个 Hackathon

回到这个比赛本身。几个关键信息：

**时间线：**

- 报名与开发期：2025年12月1日 - 12月31日
- 项目提交截止：12月31日 23:59
- 评审与发奖：2026年1月

**双赛道设计：**

**技术赛道** — 适合想动手做东西的开发者：

- 一等奖 3000元 / 二等奖 1500元×2 / 三等奖 500元×3
- 还有个"黑客先锋奖"，前 50 名完成基础任务的都能拿 100 元
- 评审维度：技术实现 40%、协作创新 30%、应用价值 20%、展示效果 10%

**社区赛道** — 适合内容创作者：

- 最佳传播奖共 10 名，奖金 200-500 元不等
- 评分 = 内容质量 50% + 传播数据 50%
- 发布平台不限：公众号、知乎、B站、小红书都行

## 值不值得参加？

我的判断：

**如果你对 Multi-Agent 有好奇心**，这是一个低成本的入场机会。完成基础任务（安装 OpenAgents、创建一个 Agent、发布 Network）就能拿 100 元，相当于边学边拿红包。

**如果你是内容创作者**，社区赛道的门槛也不高。写一篇有质量的技术解析或上手教程，跑出传播数据，500 元到手。

**如果你想认真做一个 Multi-Agent 项目**，这个比赛的评审团还算有料——有 ANP 协议的发起人、有 CAMEL AI 的核心成员、有前大厂 CTO。拿不拿奖另说，至少能获得一些有价值的反馈。
