## Page 12: TIPS

**中文**
```
1. 无测试，不开发；没完成测试，别相信你的AI同事
2. 一份经过审查的md，顶得上一百份生成的report
3. 探索协作边界而非专注挑刺，你会喜欢上AI的
4. CC很乐观，Codex很谨慎，Gemini很疯狂，且都很喜欢打补丁 :)
5. 禁止相信模型处理涉及25000token以上的文件（除非你盯着全部读完）
6. Context是一切，模型的上下文窗口还处在发展早期
7. 压缩即智能，skill.md > MCP > system prompt
8. 培养自己的架构能力，及时制止你的agent小伙伴犯蠢
9. Generated UI才是未来，数据+SaaS会成为基础设施
10. 问卷工具是human-in-the-loop里超妙的设计
```

**English**
```
1. No tests, no development. Don't trust your AI colleague until tests pass
2. One reviewed .md beats a hundred generated reports
3. Explore collaboration boundaries, not nitpick. You'll love AI
4. CC is optimistic, Codex is cautious, Gemini is wild — all love patching :)
5. Never trust models with files over 25k tokens (unless you read every line)
6. Context is everything. Model context windows are still early stage
7. Compression is intelligence: skill.md > MCP > system prompt
8. Build your architecture skills. Stop your agent buddy from being dumb
9. Generated UI is the future. Data + SaaS will become infrastructure
10. Questionnaire tools are the most brilliant design in human-in-the-loop
```
