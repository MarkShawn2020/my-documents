从社区帖子中，我也整理了一些实用的经验技巧：

**提示词结构化**：用 `**功能名称**` + 编号列表描述需求，AI 修改更精准：

```md

**信息通知**
1、点击铃铛图标，最多显示3条最新未读的消息
2、消息通知中心，不要做成弹窗，改成界面
```

**BUG 调试方法**：浏览器打开应用，按 F12 调出控制台，点击「控制台」筛选「错误」，把报错信息复制给 AI 修复。

**微信支付避坑**：对话时用 `@微信插件` 引用，但描述时要说「微信支付组件」而非「插件」，否则 AI 会跑偏。

终于我在翻了几个后，找到了一个看起来比较酷的，而且确实也还如其所是：

![https://www.miaoda.cn/projects/app-89bgiqkn7oqo](http://cdn.cs-magic.cn/picgo/20251216041130552.png?imageslim%7CimageMogr2/format/jpeg/size-limit/1000k!)

在克隆后的项目里可以看到原作者所有的创作过程，这是他的初始 prompt：

```
你是顶级视觉设计大师和前端开发专家，擅长从视觉参考中提取设计精髓并完美转化为网页设计。请为我生成一个风格高度一致的单页HTML个人主页，内嵌CSS、JS。

## 核心任务
根据用户提供的参考图和个人信息，深度解析参考图的设计语言，并将其精准转化为个人主页设计。

## 输入参数
个人信息：姓名Leon，芯片研发工程师，AI产品独立开发...
```


值得注意的是，原作者的 prompt 里指定了需要一张参考图，所以秒哒也聪明地向用户索取，但拿到参考图后，**秒哒并不是按照原作者的 prompt 直接生成 html 代码，而是先生成了一份需求文档**。

```ad-tip Spec 驱动开发

这是一种「先规划后执行」的开发范式：AI 不急于写代码，而是先将用户需求转化为结构化的需求文档（Spec），确认无误后再进入开发阶段。这种方式能显著提升复杂项目的成功率。
```

![](http://cdn.cs-magic.cn/picgo/20251216041508137.png?imageslim%7CimageMogr2/format/jpeg/size-limit/1000k!)

在原作者进一步请求生成代码后，代码才开始正式生成，并生成了最终的效果。

这个 case 的启示是 **prompt 确实挺重要，以及秒哒有自己的想法。**

此外，我们可以看到秒哒的编辑器里支持 DOM 组件捕捉（几乎成了所有 AI IDE 的共识）。目前组件的层级导航功能还在完善中，期待后续迭代。

## 实战

### （1）从一句 prompt 到一篇 prompt

秒哒的小程序按钮点击后，其实是往输入框里送入了一句生成小程序的指令：

![](http://cdn.cs-magic.cn/picgo/20251216052916172.png?imageslim%7CimageMogr2/format/jpeg/size-limit/1000k!)

我们基于它简单修改为：

```
帮我生成一个微信小程序​的应用，用于展示个人的社交名片、产品列表、文章列表、社群链接等
```

这个 prompt 过于简陋，我们还可以借助秒哒的指令优化，润色一版更详细的：

![](http://cdn.cs-magic.cn/picgo/recording_2025-12-16T1327.gif)

它修改后就变成了：

```
请帮我设计一个多功能微信小程序，用于展示个人数字名片和内容聚合平台。

1. 核心功能模块要求：
- 个人名片展示（基本信息、联系方式、社交账号）
- 产品/服务展示（支持图片、价格、详情描述）
- 文章/内容发布（分类管理、图文混排）
- 社群链接聚合（微信群、公众号、其他平台入口）...
```


**所以我们成功地从一句话 prompt 到一段话 prompt 到一篇 prompt** 🤔

秒哒的左侧栏也很有意思，从上到下，挨个是：应用、文档、代码、插件、后端服务。麻雀虽小，五脏俱全！

![](http://cdn.cs-magic.cn/picgo/20251216215620733.png?imageslim%7CimageMogr2/format/jpeg/size-limit/1000k!)
