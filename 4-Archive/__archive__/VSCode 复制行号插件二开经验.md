## VSCode 复制行号插件二开经验

最近经常有打开vscode然后复制行号回cc的需求，起初是想在行号位置进行右键复制，结果我把vscode所有复制行相关的十几个插件全装了一遍，都不支持，他们基本都只支持在编辑器内右键或者用cmd+shift+P面板，我觉得这实在太无法令人接受了，于是尝试使用cc二开

ezforo 的「Copy Relative Path and Line Numbers」插件的面板描述copy with line numbers是复数，比较深得我心，所以打算基于它魔改，恰好它还有27747个安装量（仅次于yassh的28741），16个五星star，可惜它没有给出github repo的链接；无奈，我选取了qishan233的copy-path-with-line-number，它有315个安装量，1个五星star，体验也还不错

二开时，我和cc研讨了复制文件行路径这个需求的一些产品设计建议，最终得出以下的产品优化方案：
1. 插件无需支持仅复制路径选项，因为这是vscode自带（比如在文件树或者窗口tab上右键），支持后会导致右键膨胀，用户选择成本增高
2. 要支持在行号区域、编辑区内（未选中、选中单行、选中多行）等四个场景下的右键复制动作，复制包含相对路径/绝对路径+行号的两个选项，且都处于一级菜单，极致效率
3. 语义化上，cc说条件显示line/lines比较困难，最终给出 File:Path 的程序化描述，考虑到我们的用户肯定也有一些程序基础，我觉得make sense

最后发布在了github，release成了visx供大家下载安装，暂时没有很多动力（大概要花费半小时）折腾去发布到vscode仓库，欢迎大家star、pr：https://github.com/MarkShawn2020/copy-path-with-line-number

## macOS 应用签名查看指南

在 macOS 上，您可以通过多种方式查看一个应用程序（App）的签名和开发者信息。以下是几种常用的方法：

### 方法一：使用"终端"和 `codesign` 命令（最常用）

`codesign` 是一个内置在 macOS 中的命令行工具，用于创建、检查和显示代码签名。这是获取详细签名信息最直接和可靠的方法。

1.  **打开"终端"应用程序**：
    您可以在"访达"的"应用程序"文件夹中的"实用工具"文件夹里找到它，或者通过聚焦搜索（Command + 空格键）输入"终端"来快速打开。

2.  **使用 `codesign` 命令**：
    基本的验证签名命令格式为：
    ```bash
    codesign -dvvv [应用程序路径]
    ```
    *   `-d` 表示显示（display）签名信息。
    *   `-vvv` 表示以非常详细（very verbose）的模式输出信息。

    **操作步骤示例**：

    *   假设您想查看"计算器"应用的签名信息，它通常位于 `/System/Applications/Calculator.app`。
    *   在终端中输入以下命令，然后按回车键：
        ```bash
        codesign -dvvv /System/Applications/Calculator.app
        ```
    *   **拖拽方式获取路径**：您也可以在终端中输入 `codesign -dvvv ` (注意末尾有一个空格)，然后从"访达"的"应用程序"文件夹中将您想查询的应用拖拽到终端窗口中，系统会自动填充该应用的路径。

3.  **解读输出信息**：
    执行命令后，终端会显示该应用的详细签名信息，其中可能包括：
    *   **Identifier**：应用的唯一标识符。
    *   **Format**：应用包的格式。
    *   **Authority**：签名的颁发机构。这部分会显示开发者的名称和Apple的证书信息。例如，对于Apple自家的应用，您可能会看到 "Apple Root CA", "Software Signing" 等字样。对于第三方开发者，您会看到他们的开发者ID或公司名称。
    *   **TeamIdentifier**：开发团队的唯一标识符。

    如果一个应用没有被签名，该命令会输出类似 "code object is not signed at all" 的信息。

### 方法二：通过"访达"的"显示简介"

这种方法比较简单，但提供的信息不如 `codesign` 命令详细。

1.  在"访达"中找到您想要查看的应用程序。
2.  右键点击该应用程序图标，然后选择"显示简介"。
3.  在弹出的信息窗口中，查看"通用"部分的"种类"信息。对于从 App Store 下载的应用，这里通常会显示"应用程序 (来自 App Store)"。
4.  在"更多信息"部分，您有时可以看到版权信息，其中可能包含开发者名称。

### 方法三：在 App Store 中查看

如果该应用是从 Mac App Store 下载的，您可以直接在 App Store 中找到其开发者信息。

1.  打开"App Store"应用。
2.  在搜索框中输入应用的名称并找到它。
3.  在应用详情页面，应用名称下方会明确标注开发者的名称。

### 签名的重要性

在 macOS 中，代码签名是一项重要的安全机制。它向系统和用户保证，该应用程序来自一个已知的来源（开发者），并且在签名后没有被篡改过。macOS 的"门禁"（Gatekeeper）功能会检查应用的签名，以防止用户意外运行恶意软件。默认情况下，macOS 只允许运行来自 App Store 和被认可的开发者的应用。
