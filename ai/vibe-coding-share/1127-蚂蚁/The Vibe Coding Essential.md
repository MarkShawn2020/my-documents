	- context management
		- principles
			- AVAP: As Vibe As Possible
			- ACAP: As Clear As Possible
			- ASAP: As Short As Possible 
			- AAAP: As Auto As Possible (only when high confident)
			- AVAP >> ACAP >> ASAP >> ATAP (auto is always the last option)
			- ABTP: As Active As Possible (to Passive)
			- SGB: Self-Generated is Better, see: https://arxiv.org/abs/2212.10560
			- ...
		- actions
			- clear if possible (ASAP)
			- manually composite if necessary (ASAP)
			- **revert is better than rectify** (ACAP >> ASAP)
			- slash commands >> output-style / sub-agents (ABTP)
			- skill >> mcp (ABTP)
			- meta-command, skills-creator (SGB)
		- best practice
			- `/init` upon startup (ACAP)
			- nested `/init` if necessary (ACAP)
			- code-inspector: source code >> image recognition (ACAP + ASAP)
			- Lovpen Sider: clear and short context (ACAP + ASAP + ABTP)
			- thinking slash commands: manually control thinking depth (ABTP + SGB)
			- `/fix-until-no-error`: some error fixing is iterative (AAAP)
			- `/git-commit`: each unit feature needs commit (AAAP)
			- source code comparison + step debug (ACAP + ASAP + ABTP, e.g. 全选复制粘贴)
			- e2e revert if possible (ACAP + ASAP + SGB)
	- model comparison
		- coding:
			- cc: sharp & over-confident (You Are Absolutely Right.), daily, 90%
			- codex: serious & concern, complex task, 9%
			- gemini: todo, 0%
			- human: extremely complex task, 1%
		- writing:
			- gemini: awesome & rational, 70%
			- claude: human-friendly, 20%
			- chatgpt: bottle, 9%
			- human: the last kilometer, 1%
