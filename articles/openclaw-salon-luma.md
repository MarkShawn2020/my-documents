## 活动标题

OpenClaw 北京峰会：AI Agent 的下一步

## 活动描述

**99% 的人都用反了 AI。**

涌现大于设计。Human on the Agent Loop。AI as Me。

OpenClaw 72 小时 GitHub star 破 6 万，创始人被 OpenAI 收编，NanoClaw 用 2000 行代码重写了整个 Agent 范式。不写代码的投行人冲进 GitHub 全球贡献者前 30，50 人投研团队用 Agent 缩到 5 人产出反而更高。

这些不是预测，是正在发生的事。

3 月 14 日（周六），手工川联合各大社区在北京举办 OpenClaw 峰会，把这些对话从饭桌搬到台前。

### 议题方向

- **记忆机制**：你每天和龙虾交互，其实是在把"龙虾不知道的你的偏好"变成"龙虾已知的你的偏好"。养龙虾养的到底是什么？龙虾如何越用越懂你？
- **自主进化**：龙虾如何越用越聪明？从自愈到自进化，龙虾的终局形态是什么？
- **最佳实践**：高效养龙虾的工作流——那些真正在用龙虾创造价值的人是怎么做的？
- **创投生态**：2026 是生存分水岭，如果今年还不在"桌子"上，以后就再也没机会了。龙虾赛道的投资逻辑与窗口期

### 我们想听你的声音

嘉宾与具体议程仍在筹备中，报名时请告诉我们：

- **你最想深入讨论的话题是什么？**
- **你愿意做一场闪电演讲（Lightning Talk）吗？**（5-10 分钟，任何 AI Agent 相关话题）

你的反馈将直接影响最终议程设置。

### 活动信息

- **时间**：2026 年 3 月 14 日（周六）10:00 - 18:00
- **地点**：北京（具体地点确认后更新）
- **规模**：100 人
- **费用**：早鸟票 ¥199（前 50 名） / 标准票 ¥399

### 关于我们

OpenClaw 是 2026 年最火的开源 AI Agent 项目——72 小时 GitHub 6 万星，创始人 Peter Steinberger 随后加入 OpenAI，项目转入开源基金会运营。围绕 OpenClaw 生态，已经涌现出一个跨越开发者、创业者、投资人的活跃社区。

本次峰会由手工川联合各大社区共同发起。

**当 AI 能搞定所有的 How，人最大的价值，就是去定义那个 Why。**
